# v1.7.2-rc.1 · 重新上路

Windows桌面测试版。相较上一份GitHub版本v1.5.0-rc.5，这次更新让童年记忆能在成年重新派上用场，也让每一程出发前的八张牌可以改变。

## 玩家可见变化

- 九岁的收音机与八岁的同桌故事会延续到后续童年和成年；不同选择留下不同的回应机会与真实代价。
- 新人生启程前，心气不足3点时获得一次有限休整。
- 在21、25、30、36岁前重新挑选八张随身记忆；旧牌、熟练和淬炼始终保留，换牌草稿自动保存。
- 结局记录实际成年决定、故事回响和各章带上或放回的记忆；普通路线也有自己的成年回顾。
- 换手、牌力说明、返回确认区和设置操作的触控目标得到补齐。

## 稳定性

- 更严格验证存档中的童年记忆、成年选择、结果和时间顺序，拒绝未发生或相互矛盾的记录；继续兼容v4/v5/v6正式故事。
- 修复叙事连接测试的旧请求覆盖新端点状态；关闭或离开时取消请求。
- 基础事件池独立验收；Node支持范围与锁定依赖一致。
- 游戏页面拆分为独立屏幕与共享部件，存档校验独立；浏览器与桌面测试加入TypeScript检查，减少动态效果配置有实际断言。

本地206项测试、20条浏览器旅程、生产构建、内容校验和Windows EXE启动检查通过；真实旧版规则的28,490个迁移检查点全部通过。三视口的代码、逻辑和界面终审见 [FINAL_AUDIT_1_7_2.md](../production/FINAL_AUDIT_1_7_2.md)。

这是预发行测试包。Windows安装器尚未签名，系统可能显示来源提示；真人试玩、干净账户安装升级矩阵与移动原生真机验收仍待完成。Android/iOS工程已同步，本次发布范围为Windows。
