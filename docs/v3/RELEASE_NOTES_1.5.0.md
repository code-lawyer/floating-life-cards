# 浮生牌局 1.5.0 内部发布候选

## 新增

- Windows x64 桌面应用、可执行目录与安装器；
- Capacitor iOS / Android 原生工程，同步共享规则、内容、存档语义与视觉；
- 14个童年事件、5个正式世界牌局、合同原型、15个成年生活事件、组牌与结局的剧情画面；
- 童年结束后的起手身份总结：名校毕业生、职校技术员或灵活就业者，并解释三个形成原因；
- Windows、iOS、Android共用的应用图标与启动视觉。

## 修复

- 心气、余钱或人情不足时不能再选择会透支的选项，并明确显示缺口；
- 所有原选项都无法承担时，故事用“现实替你决定”的有代价兜底继续，不再卡死；
- 同一牌局打出不同记忆牌会得到引用具体记忆、做法与胜负的不同结果叙述；
- 正式童年中的手艺路线现在确实能够生成职校技术员，不再只存在于人工构造测试；
- 运行时剧情图片从约92.7MB优化为约5.7MB WebP。

## 验证边界

- 规则、组件、存档、视觉与1000种子完整人生护栏通过；
- 1440×900、390×844触摸、844×390横屏触摸和纯键盘浏览器旅程通过；
- Windows打包后EXE启动旅程通过；
- iOS与Android工程已同步，但尚未在真机、商店签名或审核环境验证；
- Windows公开下载前仍需代码签名证书。本候选未签名，只用于内部验收。
