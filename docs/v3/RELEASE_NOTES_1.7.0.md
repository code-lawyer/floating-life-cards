# v1.7.0 · 重新上路

本地可玩开发版本。生活换了局面，你也可以重新选择带上哪些自己。

- 在21、25、30、36岁的下一程出发前，重新整理八张随身记忆，也可以保留原样。
- 所有旧牌继续保留，熟练和淬炼不会因放回牌册而消失；暂时没用上的经历以后可以再带上。
- 整理时能看下一程处境、筛选做法、恢复原牌组；草稿自动保存，刷新继续。
- 出发前显示实际心气与压力变化，确认后只结算一次休整。
- 结局逐章记录实际带上、放回或保留的决定。
- 桌面、手机竖屏与横屏都有对应布局，完整牌面保持可读，操作区不会悬浮遮挡记忆。
- v6进度原位迁移，新整理入口从后续章节出现；v4/v5保持原故事，不补造过去的记录。

质量门通过189项单元/组件测试、18条浏览器旅程和生产构建；界面对比度修正后重跑4条整理旅程。Windows可执行版通过真实EXE启动测试，iOS/Android工程同步至1.7。详细取舍与自动模拟的解释范围见 [制作决策](../production/ITERATION_1_7.md)。
