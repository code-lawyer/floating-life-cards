# v1.7「重新上路」制作决策

## 本轮目标与优先级

让玩家有机会在新的生活处境中重新选择自己的做法。上一版18岁挑出的八张牌会一直固定到结局；成年回响即使重新理解了某张旧记忆，那张牌也可能始终无法上桌。这是已有叙事与实际操作之间的断点，因此本轮先完成章节间整理，再扩写事件数量。

交付标准：下一章前可以重选八张已拥有的记忆；放回不等于遗忘；修改途中刷新可恢复；确认前看见实际休整；结局只记实际决定；旧档案原位继续；桌面与手机都能完成完整人生。不增加核心资源，不修改出牌公式，不增加付费或联网依赖。

## 玩家现在能做什么

1. 一章局面和两次成年生活结束后，在21、25、30、36岁出发前打开牌册。心气耗尽正常结卷，最终章之后直接进入结局。
2. 先读下一章的现实处境、轮次与目标；具体世界意图和时代气候仍在入场后揭晓。
3. 从全部15张真实记忆里带上八张，按洞察、行动、共情筛选；先放回再带上，也可以直接保留原来的八张。
4. 未携带的牌保持完整可读，熟练与淬炼保留。以后可以再次带回，卡牌不会因调整而删除。
5. 草稿自动保存；不足八张时明确提示并禁用出发。“恢复原来的八张”撤回本次调整，不影响资源或旧牌局。
6. 出发前显示已计入人生状态和资源上限的休整结果；确认才提交牌组、休整一次并进入下一章。
7. 结局按年龄列出带上与放回的实际牌名，也记录“保留了原来的八张”。不把每次变化都写成成长，也不把坚持写成错过。

## 界面与美术

沿用冷色纸面、档案蓝、宋体标题与去色电影静帧。整理页重新使用18岁牌册画面，让同一张桌子成为人生中的回访地点；没有另造一套与现有游戏脱节的视觉。

先呈现下一程和单一出发操作，再展开完整牌册。出发区不悬浮遮挡内容，牌册上方和末尾提供回到出发处的入口。桌面四列、窄屏横向三列、手机两列；每张牌保留记忆正文、效果、熟练与数值。结局用年龄与文字行记录变化，避免再增加一套卡片墙。

首轮画面检查发现装满八张后，未携带牌被全局禁用透明度淡化，妨碍比较；本轮已在整理页保留全文对比度，禁用仍由原生按钮语义、容量说明及选中状态区分。返回入口与恢复按钮至少44像素高。独立复核与最终截图证据见 [VISUAL_NOTES_1_7.md](./VISUAL_NOTES_1_7.md)。

## 规则、保存与迁移

`interlude` 为第十二个正式阶段。`deckDraft` 与已提交的 `selectedDeck` 分离，编辑期间保留上一场的实际牌堆，避免修改旧结果或提前消费随机数。`CONFIRM_INTERLUDE` 一次性提交八张、记录前后牌组、按预览休整、开下一章；重复动作无效。

存档升级为v7，正式与原型仍使用独立槽。v6保留当前阶段、选择事实、故事版本和已有资源，不补发休整、不伪造过去的整理；回响故事在下一次尚未发生的章节转换获得新入口。v4/v5继续迁移为classic，固定原型保持原流程。迁移回写失败仍交回可玩的会话，旧槽保留。

校验覆盖草稿所有权与容量、阶段一致性、每次整理的八张唯一牌、连续记录前后衔接，以及最后记录与当前牌组/章节一致。不满八张的合法草稿可以保存；越界、重复或伪造的牌不会进入游戏。

## 制作对照与证据边界

`npm run analyze:story -- 1000` 使用种子1–1000、同一正式规则与固定自动策略。命令新增第八组“回响内容、每章轮换一张”；轮换规则并不根据未来世界意图优化，也不模拟真人理解。

| 回响故事策略 | 走完五章 | 未结算满三章即结卷 |
| --- | ---: | ---: |
| 混合策略，保留原八张 | 84.3% | 8.7% |
| 同一混合策略，每章轮换一张 | 82.0% | 9.7% |
| 保守策略，保留原八张 | 100.0% | 0.0% |
| 轮换出牌策略，保留原八张 | 69.5% | 15.6% |

保留原组的结果与v1.6一致，章节整理没有暗中放宽恢复或出牌规则。盲目换牌不是稳定收益；这不足以证明各种构筑已平衡，更不能当作真人胜率或乐趣证据。本轮不依据该差异追加数值补偿。

## 下一制作顺序

1. 取得规则与完整人生的真人样本，加入“为什么重新带上这张牌、为什么保留原来的牌”复述，检验操作是否真正唤起记忆。
2. 扩展不同童年选择的持续人物与成年回响，优先弥补内容回报集中在少数路线的问题。
3. 让起手身份影响成年处境，并区分五章决策压力；有证据后调整事件、牌组与时间跳切。
4. 扩充个性化结局、本地多周目档案与声音；每项交付完整可玩路径。
5. 公开发行前独立完成Windows签名与干净账户生命周期，以及Android/iOS原生构建、签名和真机矩阵。

本轮交付的是可玩的章节构筑闭环，不能据此宣布整个游戏已成熟或已通过真人体验门槛。
