# 完整游戏系统地图

## 使用方法

状态含义：

- 可复用：v1 已有稳定基础，v2 主要做小幅调整。
- 需改造：已有实现，但规则或表达不能直接满足v2。
- 待开发：v2需要新增。
- 后置：完整发布可能需要，但不进入当前原型。

## 一、核心游戏循环

| 系统 | 玩家价值 | 当前状态 | v2工作 | 依赖 |
| --- | --- | --- | --- | --- |
| 单局状态机 | 保证人生按合法阶段推进 | 可复用 | 增加童年总结、时间跳切和身份阶段 | 领域状态 |
| 确定性随机 | 同种子、同行动得到同人生 | 可复用 | 支持条件事件池与身份平局处理 | 内容数据 |
| 资源系统 | 让选择与失败产生延续代价 | 可复用 | 明确属性文档和身份初始调整 | 事件、牌局 |
| 成长倾向 | 记录洞察、行动、共情偏好 | 可复用 | 限制加成上限并接入总结 | 童年事件 |

## 系统依赖主链

制作时遵循以下顺序：

成年牌局原型 → 记忆牌与回忆堆定型 → 身份被动定型 → 童年标签与路线 → 时间跳切与身份生成 → 完整内容 → 教程与平衡 → 发布。

不允许倒过来先写大量事件，因为成年牌局变化可能要求重写所有卡牌效果。
