# 成年困局原型界面验收

## 验收范围

- 日期：2026-08-18。
- 环境：Vite 开发服务器、Chromium、agent-browser 0.33.2。
- 桌面视口：1440 × 900。
- 移动视口：390 × 844。
- 路径：标题页 → 职校技术员 → 合同困局教学 → 三轮出牌 → 结案 → 同身份重试。

这是一轮真实浏览器界面验收，不替代3–5名目标玩家的规则试玩，也不等同于已经建立仓库内的自动端到端测试。

## 通过证据

### 标题与快速入口

- 页面有实际内容，无 Vite 错误覆盖层。
- “登记出生”“先读玩法说明”和三个原型身份入口均出现在交互快照中。
- 1440像素与390像素视口均无横向溢出。
- 390像素标题页完整高度为1023像素，三个身份入口按单列排列且可点击。

### 困局与身份

- 职校技术员进入“站点办公室 · 下午 16:40”，界面显示身份被动与“签字倒计时”。
- 第一轮显示4张手牌；教学第一步期间手牌不可误触，进入第二步后恢复可用。
- 移动困局按单列显示世界牌和手牌，无横向溢出。
- 桌面困局同时显示世界牌、四张手牌、预计得分和推荐牌。

### 完整闭环

浏览器实际出牌顺序为：

1. “错题地图”，局面推进到5/12。
2. “自己修好的车链”，局面推进到10/12。
3. “倒计时外的确认键”，以13/12越过局面。

结案页显示“用职校技术员再试一次”。点击后恢复到同一合同困局、同一身份、0/12、第一轮和4张手牌。

### 错误与可访问性

- 浏览器错误列表为空；控制台只有 Vite 连接和 React 开发提示，没有未解释错误。
- 标题页 WCAG A/AA 审计：0项违规、0项待人工确认、17项通过。
- 移动困局 WCAG A/AA 审计：0项违规、0项待人工确认、19项通过。
- 开发环境采样：TTFB 1.8ms、FCP 48ms、LCP 48ms、CLS 0。该数字只用于发现明显退化，不作为发布性能承诺。

## 本轮发现与修复

点击“去看我的手牌”原本只切换教学文字，不会把手牌带进视口：

- 390像素修复前，手牌区仍在当前视口下方约250像素。
- 1440像素修复前，手牌区顶部会被72像素高的粘性页头遮住。

修复后按钮会平滑滚动到手牌区，并为粘性页头保留滚动边距：

- 390像素：页头底部108像素，手牌区顶部约118像素。
- 1440像素：页头底部72像素，手牌区顶部约82像素。

组件测试验证点击教学按钮会调用手牌区滚动；真实浏览器复验验证桌面和移动定位均正确。

## 阶段判断

原型界面验收通过。阶段1剩余门槛是至少3名目标玩家的现场规则试玩，以及只针对最高影响问题完成一次调整与复测。在取得真人证据前，不扩写童年内容，也不把自动策略或本轮浏览器通关解释为“玩法已经好玩”。
