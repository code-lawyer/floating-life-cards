# 自动端到端验收

## 目的与边界

这组测试把玩家旅程固化成仓库内可重复运行的验收。成人原型从 `?playtest=adult-prototype` 专用地址开始，正式完整故事从普通标题页开始；专项测试使用正式规则生成存档检查点，经真实存储边界装载。所有玩家动作通过浏览器中的按钮、链接和键盘执行。正式故事测试会读取已保存的JSON并用公开规则选取动作或比对结果，不直接调用React内部状态推进页面。

它证明关键交互与状态保存没有回归，不证明牌局“好玩”，也不替代目标玩家的现场规则试玩。

结案旅程会授予当前本地来源剪贴板权限，再从浏览器剪贴板读取Markdown，确认构建版本、身份、逐轮事实和“不包含个人信息”声明真实进入复制结果；随后触发真实下载，读取临时文件并复核版本。它不通过React状态或模块内部对象旁路验证。

## 执行方式

首次在本机安装受控 Chromium：

```bash
npx playwright install chromium
```

只运行浏览器旅程：

```bash
npm run test:e2e
```

运行完整质量门：

```bash
npm run verify
```

完整质量门依次执行静态检查、Vitest、TypeScript与Vite生产构建、Playwright。Playwright自行启动固定端口的Vite开发服务器，测试结束后关闭。
