# 成人原型自动端到端验收

## 目的与边界

这组测试把已经通过的人工界面验收固化成仓库内可重复运行的玩家旅程。成人原型旅程从 `?playtest=adult-prototype` 专用地址开始，正式故事旅程从普通标题页开始；测试只通过浏览器中的标题、按钮、区域、焦点和可见结果操作游戏，不读取 React 状态或规则模块内部对象。

它证明当前成人原型的关键交互没有回归，不证明牌局“好玩”，也不替代目标玩家的现场规则试玩。

## 当前自动旅程

| 旅程 | 视口 | 验证行为 |
| --- | --- | --- |
| 合同困局完整闭环 | 1440 × 900 | 职校技术员进入困局、完成教学、出牌到结案、复制并读取带包版本的匿名记录、真实下载同内容Markdown、同身份重试 |
| 童年余温与移动结案 | 390 × 844，触摸 | 灵活就业者进入平台处境、验证44像素主要操作和图片解码、从回忆堆召回同一张牌、继续到结案、真实下载并读取身份与版本、无横向溢出 |
| 纯键盘首轮 | 1440 × 900 | Tab选择名校毕业生、Enter推进教学、焦点交给手牌区、下一次Tab进入“唤起”按钮并用Enter出牌 |
| 正式童年与身份跳切 | 390 × 844，触摸 | 从出生走完14年成长、验证剧情图解码与44像素目标、查看生成身份原因并进入第一场世界牌局 |
| 窄屏横屏 | 844 × 390，触摸 | 验证触摸环境、44像素主要操作、牌局画面解码和无横向溢出 |

五条旅程都会捕获未处理的页面异常和 `console.error`。失败时 Playwright 保留截图、错误上下文和追踪文件。

结案旅程会授予当前本地来源剪贴板权限，再从浏览器剪贴板读取Markdown，确认构建版本、身份、逐轮事实和“不包含个人信息”声明真实进入复制结果；随后触发真实下载，读取临时文件并复核版本。它不通过React状态或模块内部对象旁路验证。

## 执行方式

首次在本机安装受控 Chromium：

```bash
npx playwright install chromium
```

只运行浏览器旅程：

```bash
npm run test:e2e
```

运行完整质量门：

```bash
npm run verify
```

完整质量门依次执行 Vitest、TypeScript与Vite生产构建、Playwright。Playwright自行启动固定端口的Vite开发服务器，测试结束后关闭。
