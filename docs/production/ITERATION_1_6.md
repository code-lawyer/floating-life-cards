# v1.6「旧事回响」制作决策

## 本轮目标

让“人生如牌局”成为可操作、可追溯的体验：童年做过的事在成年打开另一种回答，这种回答仍有代价；失败留下故事，未使用的记忆仍属于玩家。沿用档案与电影静帧的视觉，不增加新的核心资源或联网依赖。

本轮完成标准：新故事可以从出生走到结卷；两条跨年龄故事能改变后续事件和选择；首次成年牌局有尝试余地；过去与现在在界面上可以对照；旧存档继续可玩；桌面、触摸手机、确定性回放与保存恢复都有验证。

## 已实施的制作决策

### 启程休整

新故事在确认身份、进入首场牌局时，把不足3点的心气补到3点，只执行一次。高于该值不追加收益，余钱、人情、压力不改变。身份页显示确切变化，人生档案记录实际恢复量。旧人生和固定合同原型保持原规则。

使用种子1–1000的相同混合策略对照，旧内容无休整时66.6%走完五章，最低3点方案为83.6%；统一加2点为87.2%，最低4点为88.3%。采用改动最小的最低3点方案。它不保证获胜，也不把童年代价重置掉。

### 两条具体的因果链

| 起因 | 童年延续 | 成年现场 | 真实取舍 |
| --- | --- | --- | --- |
| 9岁拆开旧收音机后盖 | 10岁继续排查、动手或求助 | 23岁维修工作的时间与报酬 | 亲自排查需要心气；付材料钱可以换确定；分工与拒绝也各有代价 |
| 8岁替同桌挡住追问 | 12岁收到转学同桌的信 | 27岁面对老朋友的求助 | 借钱、拿出时间、说明边界，以及沿用旧约定都可以成为答案 |

两条延续各有3个童年选择、2个牌面变体；成年事件各有3个普遍回应与1个需要具体过去的回应。没有对应经历时，界面说明缺口，规则层也拒绝调用；拥有经历但支付不起仍不可选。新的成年事件替换同章的一个随机事件，完整人生仍安排10次成年生活事件。

### 记忆的表现

- 战斗牌面显示记忆正文，玩家出牌前就能看到经历，而非仅在结算后读到。
- 回响事件旁展示实际获得的记忆、年龄及其与当前处境的联系。
- 特定选择可以重新理解并淬炼那一张来源明确的记忆，不随机升级另一张牌。
- 结局列出确实发生的童年—延续—成年选择；未抵达的成年故事标为尚未展开。
- 结局尾声引用实际使用次数最多的牌和真实成年决定，不编造玩家未选择过的经历。
- 同一旧物画面在收音机故事中再次出现，作为视觉回声；保持低对比背景与可访问HTML正文。

## 工程与兼容

存档版本为v6。`storyChoices`保存选择事实，`storyEdition`区分原故事与回响故事；派生出的故事链不另存一份副本。v4/v5迁移为classic，保留已发生的故事与排程，不逆向插入新事件或补发休整。旧成长选择可从牌ID可靠恢复，旧成年选择无法可靠还原时不伪造。

`story.ts`承载条件内容与故事派生，`game.ts`仍是唯一规则入口。`storySimulation.ts`通过正式reducer完整运行人生；分析工具不另写一套结算公式。内容校验包含回响来源与特殊选项引用，存档校验检查选择与实际记忆、已完成事件的关联。

## 证据边界

运行 `npm run analyze:story` 重现七组对照，运行 `npm run verify` 验证完整质量门。固定种子浏览器旅程在桌面与390像素触摸手机上从出生走到五章结局，经过两条回响、特殊回应、童年与成年结果页刷新。

自动策略不使用换手或童年余温，不能代表真人胜率、乐趣或市场留存。本轮不声称已经获得真人验证，也不把本地构建称为公开发行。

### 本轮验收记录

- `npm run verify`：18个测试文件、179项单元/组件测试、14条浏览器旅程及生产构建通过；原有3条静态告警未增加。
- `npm run validate:content`：通过；25项旧叙事标签桥接提醒保留为已知内容决定，不阻塞运行。
- 桌面1440×900、触摸手机390×844共十张完整页面截图经过独立复核。唯一要求修正的旧事旁注对比度已修复；复核者将该项评分为resolved，disposition为ship，结论范围为这项修正。
- 颜色修正后重跑两种设备的完整回响旅程及缺失经历的禁用场景，3项均通过，并重新生成生产资产。
- Windows v1.6可执行目录已生成，真实EXE启动测试通过；iOS与Android工程同步完成。移动原生编译、签名和真机表现尚未验证。
- 详细界面证据见 [VISUAL_NOTES_1_6.md](./VISUAL_NOTES_1_6.md)。

## 下一制作顺序

1. 以当前构建完成至少3份成人原型规则试玩，并收集完整人生中对具体记忆与代价的复述。只修最高影响的重复问题。
2. 在已验证的因果机制上扩展7–12岁事件池与持续人物；补齐选择分布，避免一条路线拥有全部叙事优势。
3. 让身份真正影响成年处境与事件权重，校正起手身份与成年时间跳切；为五场困局建立不同决策压力。
4. 试验章节间重新整理8张牌，让没有带上路的记忆有重新进入生活的机会。
5. 扩充结局与本地多周目档案，再推进声音、安装升级与原生真机验收。

每项扩展都应交付一个可玩闭环：玩家看见问题、作出决定、承担代价、在以后认出变化。事件数量、画面数量和测试数量不能单独证明游戏已经成熟。
