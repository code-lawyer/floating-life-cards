# 制作任务池

## 优先级定义

- P0：阻塞当前制作或可能造成数据丢失。
- P1：当前里程碑必须完成。
- P2：完整游戏需要，但不阻塞当前原型。
- P3：发布后或有证据再做。

## 下一个开发周期

周期名称：制作基础与成年牌局技术底座。

计划顺序：

1. 初始化Git并建立v1稳定基线。
2. 为v2创建可独立演进的代码分支或清晰提交序列。
3. 修正规则中“三式额外推进”与“额外牌力”的漂移。
4. 为回忆堆和童年余温补充领域类型与规则测试。
5. 只完成规则层，不先大改页面。
6. 测试通过后制作最小界面。

创意策划在此周期只需要审核一件事：童年余温是否准确表达作品主题。其他实现细节由执行制作负责。
