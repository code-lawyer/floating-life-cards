# 成人原型决策空间分析

## 目的与边界

日期：2026-08-19。

这项分析寻找明显数值死路：某个身份是否无解、某个开局动作是否直接断送整局、童年余温或换手是否成为唯一胜利钥匙。它不模拟玩家偏好，不把分支数量解释成概率，也不评价叙事、理解成本或乐趣。

运行命令：

```bash
npm run analyze:prototype
```

分析器从固定原型开局出发，在每个状态枚举正式规则允许的全部行动：唤起当前手牌、每场一次换手、从回忆堆使用一次童年余温。所有结果都通过 `reduceGame` 计算；分析器不复制得分、补牌、资源或身份规则。影响后续结算的状态相同，就只分析一次；叙事文本与日志不参与去重键。

## 制作判断

- 15个“身份 × 第一个动作”都同时保留胜法与败法，没有数值上的自动答案或死开局。
- 没有两轮速胜；最快需要三轮，公开的五轮上限仍有发挥空间。
- 童年余温出现在部分可胜路线中，不使用它也存在可胜路线；这只证明它不是通关必需，不能证明其策略贡献大小。
- 换手同样存在“使用后可胜”和“不使用也可胜”的路线；当前分析没有比较支配关系，不能据此判断它是否为最优步骤。
- 职校技术员从“自己修好的车链”开局可三轮取胜，另外两个身份最短需要四轮，说明“手艺”被动至少在一条可见路线中改变结果。
- 任意分支都不会在这场单局耗尽心气；当前失败主要来自五轮内推进不足。真人试玩应观察玩家是否仍感到压力，而不是把这个结果直接判成难度过低。

本轮不调整数值。自动分析排除了明显死路，但无法证明玩家能识别两张理由不同的合理牌；GAME-108仍需至少3名目标玩家的现场规则试玩。
