- 本机没有JDK/Android SDK，也不是macOS；iOS/Android工程已同步但尚未原生编译、签名或真机验收。
- 当前童年内容仍使用v1叙事标签，尚未全面迁移到学习、手艺、关系、担当、探索五类画像。`npm run validate:content` 现在会把未桥接的标签逐条列为不阻塞提醒（当前25项，涉及学校、故事、独处、体面、交易、协调、群体、表达、韧性、普通人）。这些牌都还有其他标签可进入画像，但这些叙事标签本身不参与身份推导，属于设计决定而非缺陷。
- 阶段1仍缺至少3名目标玩家的真人规则试玩；已收到一次误入旧流程的诊断性测试，它不能作为固定身份样本，自动策略测试也不能证明是否好玩。

## 下一开发周期

目标：取得当前构建的真人体验证据，并在已验证的因果机制上继续扩展内容；平台发行验收作为独立交付门推进。

顺序：

1. 完成三个固定身份的真人规则样本，并收集完整人生中的记忆、代价与继续意愿反馈。
2. 优先修复重复出现的最高影响问题，再扩展7–12岁事件池与持续人物。
3. 扩充身份专属处境，校正时间跳切，检验不同困局是否促使玩家有理由重新整理八张牌。
4. 完成个性化结局、多周目档案与声音；每项均交付可玩闭环。
5. 发布前另行完成干净Windows账户安装/升级/卸载、代码签名，以及Android/iOS原生编译、签名和真机矩阵。

## 真人试玩待取得的证据

规则试玩使用主持手册中的成人原型专用入口；完整人生反馈从新开故事取得，二者分别记录。核心问题是：玩家能否解释一次选择的成本、记住一张牌的来历、认出童年与成年之间的联系，说明为什么重新带上或保留一张记忆，并愿意带着失败继续。真实参与者尚未到位；不生成或冒充真人反馈，不把它写成已完成的制作门。
