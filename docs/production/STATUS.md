# 当前制作状态

## 当前阶段

阶段1：成年牌局玩法预制作，进行中。

## 已完成

- 已初始化本地Git主分支。
- 已建立v1源码、测试、截图、设计文档与v2制作计划的首个基线提交。
- 已确认依赖、构建产物、TypeScript缓存和内部临时审查文件不会进入版本库。
- 已建立制作总计划、系统地图、完整流程、任务池、质量计划与协作规则。
- 已通过锁文件完成干净安装验证；授权访问用户缓存后 `npm ci`、测试与构建均成功。
- 当前6个测试文件、39项测试全部通过。
- 当前TypeScript检查与Vite生产构建通过。
- 已修正“三式”人生状态的规则漂移：状态加成推进局面，不再重复增加牌力。
- 已将本场弃牌统一为“回忆堆”，并将存档升级为v4独立键与显式运行模式。
- 已实现每场一次的“童年余温”：召回一张回忆牌并缓解1点压力，含规则测试与玩家界面。
- 已建立名校毕业生、职校技术员、灵活就业者三个原型身份的统一被动接口，规则不写在React中。
- 已完成24岁合同困局原型：10张固定记忆、8张默认应对组、5种世界意图和公开的“签字倒计时”。
- 标题页可选择三个身份直接试玩；结果页可用同一身份、种子和牌组重新开始。
- 已用自动策略样本验证惯用手与三式两条不同牌序都能越过当前数值版本。
- 已建立真人试玩记录模板与内部证据边界。

## 当前已知缺口

- 尚无浏览器端到端自动测试。
- 尚无通用内容数据校验器、批量平衡模拟器和完整开发调试面板。
- 尚无预览部署与正式发布配置。
- 起手身份目前只有规则接口，尚未由童年总结自动生成，也尚未在时间跳切页面展示。
- 当前童年内容仍使用v1叙事标签，尚未全面迁移到学习、手艺、关系、担当、探索五类画像。
- 阶段1仍缺至少3名目标玩家的真人规则试玩；自动策略测试不能证明是否好玩。

## 下一开发周期

目标：对合同困局进行界面验收与至少3名目标玩家的规则试玩，只根据证据调整一个最高影响问题。

顺序：

1. 在桌面与390像素移动视口完成一次真实界面验收。
2. 邀请至少3名目标玩家各使用一个身份完成规则试玩。
3. 记录玩家自己的规则解释、逐轮理由和误判，不在中途教学。
4. 汇总唯一最严重的理解或策略问题，完成一次小范围调整并复测。
5. 达到阶段1退出条件后，才启动7–12岁童年分岔垂直切片。

## 当前需要创意策划参与的事项

创意策划可直接从标题页选择任一身份试玩。当前最有价值的反馈仍是两件事：童年余温是否有“旧经历重新托住现在”的感觉；三个身份被动是否准确但不过度给职业贴标签。实现细节不需要创意策划逐项确认。
