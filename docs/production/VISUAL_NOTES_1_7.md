# v1.7「重新上路」视觉延续记录

本记录以完成后的 `InterludeScreen`、`DeckJourney`、`styles.css` 末尾「A chapter pause」样式和本轮截图为依据，延续[上一版视觉记录](./VISUAL_NOTES_1_6.md)与[游戏设计案](../GAME_DESIGN.md)中的档案纸面和电影静帧。它记录一次普通扩展：成年以后可以重新选择随身的真实记忆，放回牌册不会抹去过去。没有新视觉身份、概念提案轮次、批准稿或新图像资产，也没有把本页的组成方式推广为全项目规范。

## Overview

界面的阅读顺序是上一章之后的停顿、下一章的现实处境、八张随身记忆与出发动作、实际休整、完整牌册。上一场局面和两次生活事件之后，玩家可在21、25、30、36岁前重新整理；具体世界意图仍在入场后揭晓。结局按年龄陈述实际换入、放回或保留的决定，不把所有变化都解释为成长。

**本轮延续原则：**先说明将要面对的生活，再比较自己已有的经历；主动作只负责确认这一次出发。已拥有的15张牌保持归属，八张是随身容量。此原则描述本轮已完成的流程，不建立新的全局禁令。

## Colors

沿用现有纸白（`#F7F8FC`）、档案底色（`#DCE3F7`）、墨蓝（`#17213B`）、档案蓝（`#285B8F`）与细线色（`#AEB9D3`）。墨蓝承载正文和主动作，档案蓝用于年龄、操作反馈、返回入口与已选状态。选中卡使用档案底色36%与纸白混合的浅底，配合蓝色边框及明确的状态文字；不只依靠颜色区分。

结局整理说明已由次要文字色改为已有墨色 `var(--ink)`。卡册装满时，未携带卡的按钮仍不可添加，但本页覆盖全局禁用透明度为1，使记忆与效果能够继续比较。上述两处是可读性修正，不将原先的低对比度记为视觉特征。

## Typography

当前实现沿用 `STSong / SimSun / serif` 标题与 `Microsoft YaHei / PingFang SC / sans-serif` 正文。整理页主标题为 `clamp(2.3rem, 4.3vw, 4.5rem)`、行高1.2，手机缩为 `clamp(2rem, 9.5vw, 2.5rem)`；下一章标题为1.6rem，牌册与结局整理标题为 `clamp(1.5rem, 2.6vw, 2rem)`。卡名为1.25rem，手机1.1rem；记忆正文0.86rem、行高1.8，效果0.78rem、行高1.75。年龄和容量采用等宽数字排布。

这些值是局部实现记录。继承的系统宋体显示字不因本次记录而获得新的设计系统认可，也没有新增字体令牌。

## Layout

| 区域 | 已完成的布局 | 响应式表现 |
| --- | --- | --- |
| 下一程说明 | 内容最大宽1240px；桌面介绍与下一章摘要按1.7∶1并置，间距54px | 1000px及以下顺序堆叠，间距24px；手机页面左右内距18px |
| 出发与休整 | 容量、调整说明、唯一确认按钮为三列；休整与恢复原组紧随其后，均在普通文档流中 | 1000px及以下两列，620px及以下单列；没有固定动作浮层遮住牌册 |

| 结局整理记录 | 最大宽1040px；有序列表按88px年龄列与正文列排布，间距24px | 手机年龄列52px、间距16px，仍逐条按时间阅读；没有另加卡片墙 |

桌面截图的首屏先交代下一程、容量、出发与实际休整，再开始牌册。390×844竖屏的出发区位于首屏下部，休整紧随其后；844×390短横屏需要顺序滚动阅读下一程摘要和出发区。整页捕获不能被解释为所有信息在三种视口的首屏都同时可见。

牌册筛选行和末尾各有一个回到出发处的锚点；目标使用既有粘性页头偏移变量作为滚动余量。手机筛选行的返回链接独占一行。返回链接与恢复原组按钮至少44px高，筛选按钮也至少44px高。

## Elevation & Depth

整理页复用18岁牌册的 `deck-key-art-v1.webp`，同一张桌子成为回访地点。图像仍作为右侧或顶部的背景余影：去色、压暗，桌面不透明度0.14，手机0.12；图像不承载规则和选择文字。没有新增栅格资产，也没有为每张记忆重复放置图片。

本轮卡册取消牌面的投影，以纸面色差、细线和状态文字建立区分；可操作牌悬停轻移2px。页面继承减少动态效果设置，截图使用该设置，因此不构成通常动效体验的验收。既有主按钮硬偏移投影仍存在，未将其确立为新组件应继承的规则。

## Shapes

卡册使用12px圆角、1px细边框，桌面内距20px、最小高275px；手机内距14px／12px、最小高270px。选中卡去掉原有附加标记，改由卡外的“随身”“这次带上”“留在牌册”与浅底、边框共同表达状态。下一章摘要、出发区和结局各年龄行使用细分隔线组织阅读；这些线服务当前内容分组，并非新装饰体系。

## Components

- **章节整理 `InterludeScreen`**：顶部展示下一章标题、处境、轮数和目标。八张齐全才可出发；不足时显示差额。说明分别覆盖原样保留和实际换入／放回数量。恢复原来的八张与确认出发是两个明确动作，休整文案展示计入人生状态与资源上限后的当前值到结果值；预览不提前兑现休整。
- **记忆牌与筛选**：继续复用 `CardFace`。原生按钮提供禁用语义与 `aria-pressed`；隐藏的动作前缀说明“放回牌册”或“带上记忆”。筛选按钮以 `aria-pressed` 标记当前做法，操作反馈使用 `role="status"`。满八张时先放回再添加，暂时放回仍保留记忆、熟练和淬炼。没有相应做法时提供空状态说明。
- **结局行囊 `DeckJourney`**：只在存在实际整理记录时渲染。按章节年龄列出真实牌名；21岁换入「不在场证明」、25岁重新带回「规则草案」的截图与30、36岁“保留了原来的八张”并列呈现。没有旧记录时不补造。年龄行含避免拆页的样式，但本轮没有打印输出证据。

## Do's and Don'ts

- **Do** 先让下一程处境、容量与确认结果可读，再展开全部经历；短横屏按真实文档流滚动阅读。
- **Do** 保留未携带牌的完整比较信息，以原生禁用语义、容量提示与状态文字表达限制。
- **Do** 从实际记录生成结局；保留原八张同样是已发生的决定。
- **Don't** 将放回牌册描述为删除、遗忘或失去熟练，也不补写迁移前没有保存的整理。
- **Don't** 将本轮局部尺寸、继承缺陷或截图中的确定性测试路线升级为全游戏规范与真人体验结论。
