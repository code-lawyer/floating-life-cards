# 阶段1真人试玩综合协议

> 在读取三份样本前固定判定规则。小样本只用于发现核心玩法风险，不估算市场比例，也不把礼貌性的“挺好”当成通过证据。

## 证据顺序

同一结论出现冲突时，按以下顺序判断：

1. 玩家实际操作、停顿、重试或放弃。
2. 玩家操作当时说出的理由和预测。
3. 结案后对具体回合的复述。
4. 一般性评价与主动提出的功能愿望。

主持人的解释、自动策略和制作人的推断不能替代前三类真人证据。

## 样本有效性

三份正式样本必须：

- 来自同一个构建版本，分别覆盖三个起手身份。
- 使用匿名编号 P1-01、P1-02、P1-03，不记录姓名与联系方式。
- 玩家未参与本原型设计，至少一人从未玩过卡组构筑游戏。
- 玩家独立操作；主持人没有提前解释克制、连招、换手或童年余温。
- 有客观记录和现场观察；阻断中止时则有明确复现步骤。

不同构建的样本只用于定位问题，不能拼成阶段1通过样本。

## 阶段1通过门槛

### 不可被其他好评抵消的硬门槛

- 三份样本有效且版本一致。
- 没有白屏、卡死、错误结算、永久丢牌或无法保存记录等阻断/严重问题。
- 三名玩家都能在结案前自行理解记忆牌仍属于自己，并能解释自己的身份被动。
- 没有玩家因身份表达感到被贬低而要求停止；若两名玩家独立把三个身份理解为高低等级，直接未通过。

任何一项不满足，阶段1不通过。

### 核心玩法与主题门槛

以下七项达到规定人数或跨样本条件：

| 判定 | 门槛 |
| --- | --- |
| 第一次出牌前能说清当前目标 | 至少 2 / 3；第三人必须通过界面自行修正，不能靠主持人解释 |
| 能在出牌前预测至少一次结果方向 | 至少 2 / 3 |
| 至少一轮认真考虑两张理由不同的牌 | 至少 2 / 3，理由不能只是“预计分更大” |
| 记忆内容而非纯数值进入出牌理由 | 至少 2 / 3 主动提到牌面经历与当前处境的联系 |
| 真人实际走出不同打法 | 三份客观记录至少出现两条不同的前两轮牌序，且玩家能解释差异；不能只引用自动分析中的理论路线 |
| 童年余温同时产生策略与记忆联系 | 至少 2 / 3 使用或认真考虑；至多一人只把它理解为普通减压 |
| 主动选择重试，或明确想进入下一场困局 | 至少 2 / 3，以行为和具体理由优先于礼貌回答 |

自动决策空间已经证明存在多条胜败路径，但不能替代“两张牌为什么都想出”的真人证据。

## 问题排序

不把所有反馈都变成待办。按以下顺序只选一个最高影响问题：

1. 阻断、错误结算、永久丢牌、身份伤害。
2. 至少两名玩家重复出现的同一行为问题。
3. 一名玩家出现、但会让目标玩家无法继续的严重理解问题。
4. 单人偏好、功能愿望和纯装饰意见，只记录，不进入当前周期。

若多个问题并列，先修体验漏斗中最早发生的一项：目标理解 → 结果预测 → 出牌取舍 → 童年余温 → 继续意愿。上游问题可能制造所有下游问题。

## 改动边界

| 证据 | 优先尝试 | 本轮不直接做 |
| --- | --- | --- |
| 看不懂目标或牌会回来 | 信息层级、术语、教学时机 | 增加更多规则 |
| 只看最高预计分，没有取舍 | 调整手牌构成、意图或小幅数值 | 直接加入能量、装备、多卡排序 |
| 童年余温只是回血 | 强化记忆重现、召回反馈与使用语境 | 单纯提高恢复数值 |
| 身份像高低等级或刻板标签 | 改处境叙事、被动表达与形成原因 | 删除身份因果或用模糊词回避问题 |
| 都理解但不想继续 | 先查回合节奏、重复感和结案期待 | 立即批量制作第二场困局 |

单卡回合只有在小范围调整后，真人仍重复报告“没有两种合理选择”时，才重新评估一次性双牌回应。

## 制作结论

三份样本只能产生以下一种结论：

- **通过**：硬门槛和七项核心门槛全部达到。不为“显得有进展”强行改动，锁定成年牌局规则并启动7–12岁垂直切片。
- **调整后重测**：选定唯一最高影响问题，完成一个最小改动、升级构建版本并重跑质量门。正式退出阶段1仍需新构建上的三份有效样本，旧样本不能补人数。
- **推翻假设**：三名玩家都没有真实取舍、都只想跳过牌局，或童年余温完全无法承载主题。停止扩内容，重新设计成年核心回合。
