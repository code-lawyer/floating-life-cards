# 《浮生牌局》v2 开发文档

本目录保留早期v2目标设计，便于追溯产品决策。当前v1.5.0已经实现永久记忆循环、童年生成三种起手身份与时间跳切；尚未实现的动态学段与更大内容池仍可参考这里。判断当前代码边界应以 ../GAME_DESIGN.md、../ARCHITECTURE.md 和 ../v3/RELEASE_PLAN.md 为准，不能把本目录的全部设想当作已实现功能。

## 已确认方向

- 游戏只有童年攒牌和成年打牌两个主体阶段。
- 不引入 MBTI，也不制作完整人生模拟器。
- 保留洞察、行动、共情三项成长倾向与心气、余钱、人情、压力四项资源。
- 童年事件不再每局完全相同，早期选择会改变后续事件池和成长路线。
- 童年结束后通过时间跳切直接生成成年起手身份，不游玩大学或初职起步章。
- 记忆牌永久属于玩家；成年困局中可以进入回忆堆，但不会因出牌而从人生中消失。
- 成年牌局保持低学习成本，通过公开局势、组合、身份被动和童年余温提供轻度博弈。
- 失败写入人生并改变后续故事，不以读档或重开作为默认惩罚。

## 文档导航

- ../production/README.md：项目总制作计划、阶段门槛、系统地图、任务池与质量流程。
- PRODUCT.md：产品定位、体验支柱与明确不做的事情。
- ATTRIBUTE_SYSTEM.md：三项成长倾向、四项境遇资源与五类记忆标签画像。
- GAME_DESIGN.md：两阶段流程、成长路线、起手身份与成年牌局。
- ADULT_PROTOTYPE.md：合同困局、固定记忆池、三身份档案与原型验收标准。
- CONTENT_GUIDE.md：事件、记忆牌、身份和困局的写作与数据规范。
- TECHNICAL_PLAN.md：从当前 v1 迁移到 v2 的状态、模块与测试计划。
- ROADMAP.md：开发顺序、验收标准和仍待讨论的问题。
- ../CARD_GAME_REFERENCES.md：市场卡牌与叙事游戏参考研究。
- ../../CONTEXT.md：项目统一领域词汇。

## 文档优先级

讨论中出现冲突时，先更新 PRODUCT.md 的产品边界，再更新 GAME_DESIGN.md；技术计划必须服从玩法文档，内容规范必须服从产品基调。未进入“已确认方向”的方案都应保留在 ROADMAP.md 的待决定事项中，而不是直接写成既定规则。

制作顺序、阶段状态和下一任务由 ../production/README.md 及其任务池维护；本目录只定义要做成什么样的游戏。
